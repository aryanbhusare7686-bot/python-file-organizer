# Python File Organizer
A simple Python automation project that organizes files in the Downloads folder based on their file type.

## Features
- Organizes images into the Images folder
- Organizes documents into the Documents folder
- Moves other file types into the Others folder
- Handles duplicate filenames automatically
- Includes error handling

## Technologies Used
- Python
- pathlib

## How It Works
The program scans the Downloads folder, checks each file's extension, and moves the file into the appropriate folder.
